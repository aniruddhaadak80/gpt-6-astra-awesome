# 04 - Subagent delegation

Astra can parallelize but under-delegates unless told when.

```text
If work can be parallelized by delegating to another agent via collaboration tools - and it would save time or improve quality - do so. Define each subagent's inputs, expected output, and done criteria. Require evidence links in handoffs. Merge results into a single coherent voice and resolve conflicts explicitly. Note rate/cost caps and persist working notes so context survives compaction.
```

Use for: research splits, design+code+QA crews, map-reduce doc reviews. See `../prompts/22-multi-agent.md`.

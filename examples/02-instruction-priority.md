# 02 — Instruction priority & transparency

Astra follows long instructions well but is sensitive to `SKILL.md` / `AGENTS.md` conflicts.

```text
The user's instructions in this prompt take precedence over skill and project-file guidelines. If you must pause, ask for confirmation, leave requested work unfinished, or diverge from intent, name and link the exact skill file you read, quote the specific instruction, and explain how it affected you. Distinguish explicit user instructions from inferred context. Prefer the smallest fix that unblocks the user's goal.
```

Hygiene: audit skill files, delete stale rules, keep one authoritative voice per topic.

## ⚡ Quickstart

**Pick effort deliberately.** Start `low`/`medium` + planning; escalate to `high`/`xhigh`/`max` only after a documented miss with repro + logs. See [`prompts/25-reasoning-effort.md`](prompts/25-reasoning-effort.md).

```python
# Responses API (tool calling) — recommended
from openai import OpenAI
client = OpenAI()
resp = client.responses.create(
    model="gpt-6-astra",
    reasoning={"effort": "medium"},
    input="Build a booking-page QA pass. Test nav, forms, mobile. Report tested/failed/unverified.",
)
print(resp.output_text)
```

```javascript
// Node — Responses API
import OpenAI from "openai";
const client = new OpenAI();
const r = await client.responses.create({
  model: "gpt-6-astra",
  reasoning: { effort: "medium" },
  input: "Reconcile these two CSVs. Preserve raws. Output exceptions with reasons.",
});
console.log(r.output_text);
```

```bash
# Copilot CLI / Codex
# select `gpt-6-astra` in the model picker, then:
# $openai-docs migrate this project to GPT-6 Astra
```

Migration checklist: Responses API → drop `temperature`/`top_p`/`logprobs` → set effort → fix cache config → audit `AGENTS.md`/`SKILL.md` priority → re-baseline evals → pin per-task effort. Full pack: [`prompts/26-migration.md`](prompts/26-migration.md).

## 🧩 Astra Prompt Framework

Official guidance converges on five tunable behaviors + a five-part task shell. Every prompt in `prompts/` uses this shell.

**Five behaviors to set explicitly:**

| # | Behavior | If unset… | Set it like… |
|---|---|---|---|
| 1 | Initiative & follow-through | asks when you wanted action | “Bias toward action; deliver a reviewable result before asking approval.” |
| 2 | Instruction priority | `SKILL.md`/`AGENTS.md` conflicts stall it | “These instructions outrank skill files; quote the blocker if you pause.” |
| 3 | Writing style | verbose list/table slop | “Concise paragraphs, one idea each; lists only when parallel; plain verbs.” |
| 4 | Subagent delegation | under-parallelizes | “Delegate independent chunks via collaboration tools; merge in one voice.” |
| 5 | Testing & verification | tiny diff → full suite | “Scale checks to risk; targeted for reversible, full for risky.” |

**Five-part task shell (copy this):**

```text
Goal: [deliverable + who it's for]
Inputs: [files/links/data + what is authoritative vs reference]
Constraints: [scope, style, perf, privacy, stop-before-X rules]
Output: [format, length, acceptance criteria]
Done: [definition of done + verification report: tested/failed/unverified + assumptions]
Autonomy: [assume-vs-ask policy + approval gates + instruction priority]
```

Production-grade worked examples: [`examples/`](examples/) (initiative, priority, concise style, delegation, verification, API config). Style blocklist (“delve into”, “it’s worth noting”, contrastive “X, not Y”, fake hyphen compounds) in [`examples/03-concise-writing.md`](examples/03-concise-writing.md).

## 🛡️ Safety

- Astra is the **first Critical-cyber-capability model** per OpenAI. This repo is **defensive-only**: no exploit dev, no safeguard bypass, no jailbreaks. `07-defensive-security` is triage/hardening/detection/recovery.
- Computer-use prompts always include **stop gates**: no send/purchase/book/delete/permission-change/share without approval; least-privilege folders/apps/sites; evidence logs; PII redaction.
- Enterprise: access off by default; restrict sites/apps, uploads/downloads, history; use confirmations + auto-review of tool calls.
- If the misalignment monitor pauses a task, review before continuing. Calibrate to reduce friction without widening scope.
- See [`SECURITY.md`](SECURITY.md) for reporting + safe-use rules.
